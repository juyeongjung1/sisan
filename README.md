# 資産管理一元化ダッシュボード (Sisan Dashboard)

分散している投資資産（楽天証券、SBI証券、マネックス証券、銀行等）を一元管理し、**「為替要因」と「原資産の成長要因」を明確に分解・可視化**できるWebアプリケーションです。

スマホ・PC両対応で、毎月の積立設定や為替シミュレーターも完備しています。

---

## 🌟 主な機能

### 1. 資産・ポートフォリオの一元可視化
- **総資産・損益サマリー**: 評価額合計、投資元本、トータル含み損益（損益率）
- **アロケーション円グラフ**:
  - **実質通貨別エクスポージャー**（オルカンやS&P500などの実質米ドル比率を可視化）
  - **資産クラス別配分**（海外株式、海外債券、国内株式、現金など）
  - **口座別配分**（楽天証券、SBI証券、マネックス証券、銀行等）

### 2. 為替要因・資産成長要因の損益分解（海外投信特化）
円建てで購入した海外投資信託のリターンを、以下の3要素に完全分解：
1. **📈 原資産成長要因**: 為替が変わらなかった場合の株価・基準価額の上昇益
2. **💱 為替変動要因**: 円安（または円高）による利益・損失
3. **✨ 相乗要因**: 増えた外貨利益に対して円安が乗算された掛け算効果

### 3. 為替変動シミュレーター
- スライダーで USD/JPY を自由に変更（100円〜180円）
- 「もし1ドル＝130円になったら総資産はどうなるか？」をリアルタイム試算

### 4. 毎月の定期積立設定 (つみたて投資管理)
- 口座・銘柄ごとの毎月の積立指定日・積立額・決済方法（クレカ等）を管理
- 毎月の積立合計額と直近の次回積立予定日を表示
- 1年後〜10年後の将来資産推移シミュレーション（複利計算）

### 5. スマホ最適化 & 安全なデータ保持
- スマートフォンで片手で確認しやすいモバイルタブナビゲーション
- データはお手元の端末のブラウザ内（LocalStorage）に安全に保存（外部サーバーに資産情報が漏洩しません）
- JSONバックアップ保存・復元、CSV出力対応

## 🚀 使い方 (ローカル起動)

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 📱 スマホで簡単に確認するための公開方法 (Vercelデプロイ)

本アプリは Next.js 製のため、**Vercel (無料)** に連携するだけで、スマホからいつでもアクセスできる専用URLが発行されます。

1. [Vercel](https://vercel.com) にアクセスしてGitHubアカウントでログイン
2. **「Add New...」 -> 「Project」** をクリック
3. リポジトリ一覧から `juyeongjung1/sisan` を選択して **「Deploy」** をクリック
4. 数十秒で専用のURL（例: `https://sisan-xxxx.vercel.app`）が発行されます
5. そのURLをスマホのブラウザで開き、**「ホーム画面に追加」** すると、アプリ感覚でいつでも資産・積立状況を確認できます！
